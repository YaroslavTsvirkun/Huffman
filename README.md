# Huffman

Невеликий навчальний проєкт на C#, який реалізує кодування та декодування рядків за алгоритмом Хаффмана.

## Що є в репозиторії

- `Huffman Compressor` — бібліотека з реалізацією побудови дерева Хаффмана, кодування та декодування.
- `HuffmanTest` — консольний застосунок для ручної перевірки роботи алгоритму.
- `Huffman.slnx` — solution-файл у сучасному форматі `.slnx`.

## Можливості

- підрахунок частоти символів у вхідному рядку;
- побудова дерева Хаффмана;
- кодування рядка у бітову послідовність;
- декодування бітової послідовності назад у вихідний рядок.

## Вимоги

- .NET SDK 10 або новіший.

Перевірити встановлений SDK:

```powershell
dotnet --list-sdks
```

## Збірка

```powershell
dotnet build .\Huffman.slnx
```

## Запуск прикладу

```powershell
dotnet run --project .\HuffmanTest\HuffmanTest.csproj
```

Після запуску консоль попросить ввести рядок, потім виведе:

- закодовану бітову послідовність;
- декодований результат.

## Приклад

Для введення `hello` застосунок виводить закодовані біти та потім повертає:

```text
Decoded: hello
```

```text
Huffman/
```

## Примітка

Це компактний демонстраційний проєкт. Він підходить для вивчення алгоритму Хаффмана, але не виглядає як готова production-бібліотека з тестами, API-документацією та обробкою крайових випадків.
